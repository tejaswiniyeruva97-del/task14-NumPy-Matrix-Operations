Internship Task – Veda Technology

1. Project Description

This project demonstrates basic matrix operations using Python and the NumPy library.

Two matrices are created and four operations are performed:

Matrix Addition
Matrix Subtraction
Matrix Multiplication
Matrix Transpose
2. Objective

To understand basic matrix operations used in mathematics and machine learning.

7. Matrix Multiplication Explanation

Matrix multiplication is performed by multiplying the rows of the first matrix with the columns of the second matrix and adding the products.

For example:

(1 × 5) + (2 × 7) = 19
